## 2. Rules

- **No mocks of our own infrastructure** in integration tests: real Postgres, real Kafka (CI), real Temporal test server. External providers use their sandbox adapters, which are labelled as sandbox (brief §92).
- Every bug fix adds a test that fails without the fix.
- Coverage target: at least 80% lines on domain and application code, measured per package; coverage is a floor, not the goal.
- Tests must be deterministic: injected clocks, seeded ids where order matters, no sleeps (use the time-skipping server or polling with deadlines).
- Seed and demo data (demo company) double as E2E fixtures.
